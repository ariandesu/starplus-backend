## Synthetic data

All data in this project is synthetic. No data row came from NASA or any space agency;
28 published OSDR values were used only as a plausibility reference:

- `starplus-backend/ml/data/astronaut_health_SYNTHETIC.csv` (1,260 rows, 180 invented crew)
  was generated by a computer program from published group-level statistics. See
  `ml/data/how_data_was_generated.txt`, which must be read before citing this file.
- Demo, load-test and smoke-test crews (`demo`, `stg-*`, `smoke-*`) are synthetic and
  labelled `synthetic` or `simulated_device` in the database.
- Records carry a `provenance` field (`real`, `synthetic`, `simulated_device`); synthetic
  and simulated readings earn no gamification points and are excluded from crew progress.
