# Disclosure

## What existed before 2026-11-14

STAR PLUS began as an earlier astronaut-health dashboard project in the same folder
(`STAR_PLUS_ASTRONAUT_DATASET`): a synthetic-data rehearsal with 28 serum glucose values
from 4 Inspiration4 crew (NASA OSDR, OSD-575) used only as a plausibility reference, plus
group-level statistics from published studies. No product code, no model, no content, and
no infrastructure from that work is part of this submission beyond the synthetic CSV
described below. Everything in `starplus-backend/` and `starplus-frontend/` was built for
this event.

## Synthetic data

All data in this project is synthetic. No row is a real person's measurement, and nothing
came from NASA or any space agency:

- `starplus-backend/ml/data/astronaut_health_SYNTHETIC.csv` (1,260 rows, 180 invented crew)
  was generated by a computer program from published group-level statistics. See
  `ml/data/how_data_was_generated.txt`, which must be read before citing this file.
- Demo, load-test and smoke-test crews (`demo`, `stg-*`, `smoke-*`) are synthetic and
  labelled `synthetic` or `simulated_device` in the database.
- Records carry a `provenance` field (`real`, `synthetic`, `simulated_device`); synthetic
  and simulated readings earn no gamification points and are excluded from crew progress.

## AI tools used

- **Claude** (Anthropic) for software development: design, code, tests and docs in this
  repo, working from the author's plan.
- **Meta Muse Spark in Contributor mode** for build-time explanations: the shipped
  explanation cache (`core/content/explain-cache.json`) was generated at build time and
  every entry was reviewed by a human (`status: "reviewed"`) before shipping.

## No clinical review

No clinician has reviewed the limits, guidance text, formulary entries, model output or
explanations. Thresholds are starting points for review, not clinical guidance. This is a
hackathon prototype, not a medical device.
